# 软件项目综合实践

## 项目概述

Go语言书城项目是一个基于Go语言开发的在线图书商城系统，旨在为校园用户提供便捷的图书浏览、购买和管理服务。本项目是软件项目综合实践的课程作业，由404回收站团队负责开发和交付。

## 项目信息

- **项目名称**: Go语言书城项目
- **项目标识**: GOBOOKSTORE-2025-001
- **版本**: V1.0
- **开发团队**: 404回收站（13名核心成员 + 3名支持人员）
- **项目周期**: 2025年9月8日 - 2025年12月15日（99天）
- **项目性质**: 开发型项目（校园级在线购书平台）

## 技术架构

### 技术栈

#### 后端技术
- **开发语言**: Go 1.22+
- **Web框架**: Gin（标准库 net/http）
- **数据库**: MySQL 8.0
- **ORM**: GORM
- **架构模式**: MVC（Model-View-Controller）

#### 前端技术
- **HTML/CSS/JavaScript**: 基础前端技术
- **框架**: Vue 3 / React（部分页面）
- **UI框架**: Bootstrap 5
- **工具库**: jQuery

#### 开发工具与基础设施
- **容器化**: Docker + Docker Compose
- **版本控制**: Git (GitFlow)
- **CI/CD**: GitHub Actions / Jenkins
- **监控**: Prometheus + Grafana
- **测试工具**: Postman, JMeter

### 功能模块
- **6大核心功能模块**:
  - 用户管理模块（注册、登录、会话管理）
  - 图书管理模块（图书CRUD、分类、搜索）
  - 购物车模块（添加、修改、删除商品）
  - 订单管理模块（订单创建、状态流转、查询）
  - 管理员后台模块（图书、订单、用户管理）
  - 公共服务模块（数据统计、系统通知）
- **22个核心功能用例**: 完整覆盖用户购书全流程
- **9类核心页面**: 覆盖用户与管理员全场景操作
- **38个RESTful接口**: 支持前后端分离架构

### 数据库设计

  - carts（购物车表）
  - cart_items（购物项表）
  - orders（订单表）
  - order_items（订单项表）
  - sessions（会话表）
- **初始数据**: 100条图书数据（教材、学术书、课外书分类）

## 经验总结

### 成功经验
1. **阶段性项目管理**: 采用瀑布模型与迭代开发相结合的方式
2. **需求评审机制**: 通过原型验证和评审会确认需求准确性
3. **技术选型务实**: 采用成熟技术栈，快速上手
4. **重视单元测试**: 从开发初期编写测试，保障代码质量

### 主要教训
1. **并发处理设计缺失**: 核心业务场景的并发控制需要加强
2. **健壮性与容错性**: 对异常输入的处理不够完善
3. **安全措施不足**: 密码加密、输入验证等基础安全需要强化
4. **测试质量**: 测试用例设计的深度和广度需要提升

### 改进建议
1. **并发控制前置**: 并发锁、事务处理应在设计阶段充分考虑
2. **安全是红线**: 密码加密、HTTPS、输入验证必须严格落实
3. **测试质量重于数量**: 重点覆盖并发、边界、异常、安全攻击场景
4. **流程与工具并重**: 通过工具固化流程，避免"纸上谈兵"
